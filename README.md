# AniManga-Central
O AniManga Central é uma plataforma digital dedicada aos fãs de animes e mangás. Oferece busca de títulos, catálogo de obras populares, fichas técnicas, sinopses, destaques e notícias. Com design moderno, tema escuro e interface responsiva, busca proporcionar uma experiência intuitiva e agradável aos apaixonados pela cultura japonesa.
